<summary><b>💸 Shared Expense Tracker</b> — full-stack Flask web app</summary>
<br/>

Built a full-stack web application in Flask that lets groups log shared expenses, split costs, and track who owes whom, with session-based user authentication. Designed and implemented RESTful API endpoints for creating groups, adding expenses, and computing balances, backed by a SQL database for persistent storage. Implemented automatic expense-splitting logic and a settlement-suggestion algorithm to minimize the number of transactions needed to settle group balances, using Jinja2 for server-rendered views.

`Python` `Flask` `SQL` `REST APIs`
